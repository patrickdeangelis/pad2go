No macOS não há controle Xbox virtual: o Pad2Go envia botões, analógicos e movimento para emuladores (como o Eden) via DSU.

Conexão automática
    Como conectar
    1. Desligue o Switch 2 ou ative o modo avião. Ligado e por perto, ele chama os controles de volta.
    2. Segure o botão SYNC até as luzes correrem de um lado para o outro.
      • Joy-Con 2: botão redondo pequeno na face interna (o lado que encaixa no console), entre SL e SR. Faça em cada um.
      • Pro Controller 2 e controle GameCube: botão na parte de cima, perto da entrada USB-C.
    3. O Pad2Go conecta sozinho. Com “Unir Joy-Cons” ligado, o esquerdo e o direito viram um só jogador.
    4. Depois do primeiro pareamento, basta apertar qualquer botão para reconectar.
    Para voltar a usar no Switch 2, encaixe os Joy-Cons no console ou conecte o Pro Controller pelo cabo.
    Controle pareado com outro PCA preferência será salva e as conexões serão reiniciadas.

    Jogadores

    Controle novo ou que estava no Switch 2? Segure SYNC até as luzes correrem.
